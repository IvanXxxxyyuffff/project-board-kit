## 5 这轮最值钱的三条教训

1. **「链路绿」不等于「数据对」**：这一轮一半的 bug 是判据写松了（`sheets=\d+`、`at` 用运行时刻、`/` 当完成日期），门禁全绿仍然会显示错数据。
2. **导出链有两个真源**：`.github\workflows` 之类文件在业务仓根和 `_business\repo_overlay` 各有一份，overlay 覆盖前者。改错了地方，本地看是新的、远端跑的是旧的；`guard_meta` 的 PARITY 只覆盖它列出的文件。
3. **只看 HTTP 200 会骗人**：GitHub 的付费安全开关 PATCH 返 200 但值被忽略；`gh push --force` 也不删历史。开关要回读、历史要删仓。
